# LeaseOS — Compliance & Permits Paperwork Template Pack

This ZIP contains printable PDF paperwork templates for the four requested compliance areas:
- DOT / FMCSA registration & authority
- Oilfield waste tracking / generator compliance
- NORM survey & handling
- Environmental compliance / spill reporting

The pack intentionally includes both the master forms and supporting paperwork used to maintain a compliance file.

IMPORTANT:
These are internal templates, not official government forms. The application should distinguish a LeaseOS-generated record from an official agency filing.

FMCSA currently provides official registration/authority workflows and forms through its Registration Forms resources. See:
https://www.fmcsa.dot.gov/registration/registration-forms

EPA's hazardous-waste manifest system tracks qualifying off-site hazardous waste shipments. Use the official manifest/e-Manifest process when applicable; this template pack only provides an internal tracking wrapper:
https://www.epa.gov/hwgenerators/hazardous-waste-manifest-system
https://www.epa.gov/e-manifest/how-submit-hazardous-waste-manifest

State, tribal, and local requirements can add or modify requirements. NORM requirements are especially jurisdiction-specific.
