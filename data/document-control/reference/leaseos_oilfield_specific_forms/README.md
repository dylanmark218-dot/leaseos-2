# LeaseOS — Oil Field Specific Forms

Included:
- Waste Manifest / Hazardous Waste Manifest — Internal Record
- Disposal Ticket / Waste Disposal Receipt
- Oilfield Load Ticket / Load Record
- Oil Field Specific Forms Master Index

IMPORTANT:
The Waste Manifest PDF is intentionally an internal companion record. It is NOT the official EPA Uniform Hazardous Waste Manifest. If a shipment is subject to federal/state hazardous-waste manifest requirements, the current official manifest/e-Manifest process must be used.

EPA reference:
https://www.epa.gov/hwgenerators/hazardous-waste-manifest-system
https://www.epa.gov/e-manifest

The forms include NORM-related fields where useful, but NORM and oilfield waste regulation is jurisdiction-specific and should be mapped to the applicable state program.
